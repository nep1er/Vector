# resources — общие ресурсы интерфейса

Папка одинакова для Web, Desktop и Mobile: единый стиль везде. Копируется целиком.

| Папка | Содержимое |
|---|---|
| `design/tokens.json` | **Источник правды**: цвета, радиусы, отступы, шрифт, тени, градиенты проектов. Его читают Desktop и Mobile. |
| `design/tokens.css` | Переменные для Web. Генерируется: `node resources/design/build-tokens.mjs` |
| `brand/` | Логотип и favicon |
| `icons/` | Иконки 24×24, `stroke="currentColor"` — цвет задаётся цветом текста |

Правила:
- Цвет или размер меняем только в `tokens.json`, затем запускаем `build-tokens.mjs`.
- Новая иконка — SVG 24×24, `stroke-width="1.75"`, скруглённые концы, без `fill` и без жёстких цветов.
- Web подключает ресурсы напрямую из этой папки (`client` лежит рядом с `resources`).
